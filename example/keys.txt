# lumalinux depot key store — EXAMPLE for v0.3
#
# Copy to ~/.config/lumalinux/keys.txt and populate.
#
# ─── Two line formats supported ────────────────────────────────────────────
#
# 1) LEGACY (just key, no injection):
#    <depot_id>;<64-hex-key>
#
#    Use this for depots Steam already knows about (shared dependencies,
#    single-depot games via SLSsteam, etc.). lumalinux will only SERVE the
#    key when Steam asks for it.
#
# 2) EXTENDED (key + injection metadata):
#    <depot_id>;<parent_app_id>;<manifest_gid>;<manifest_size>;<64-hex-key>
#
#    Use this for CONTENT depots that Valve filters out of appinfo for
#    unowned apps (typical case: any multi-depot pirated game on Linux).
#    lumalinux will INJECT this depot into Steam's pDepotInfo when it builds
#    the dependency list for parent_app_id.
#
#    manifest_gid & manifest_size come from the SteamTools .lua:
#      setManifestid(<depot_id>, "<gid>", <size>)
#
# Lines starting with # are comments. Blank lines ignored.
#
# ─── Example: Balatro (parent app 2379780) ─────────────────────────────────
